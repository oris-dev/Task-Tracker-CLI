task:
deadline - (date)
created - (date)
status - (on-progress to-do completed removed)
priority - (high medium+ medium low+ low)
categories - create whatever categories, up to 3 categories per task
instructions - a new window that pops up that simplifies the progress for you to make the task with less friction

views: (default to never show tasks that are on status removed or completed )
view tasks by a specific deadline
view tasks by date created
view tasks by status
view tasks by priority
view tasks by catagories 

functions:
add a task
remove a task
update a part of the task - deadline, status, priority, catagories or insturctions
review insturctions in a module screen 
create AI simplification of the task
create AI recommendation on how to do the task differently
create AI anaylse about how am I completing my tasks lately and review on what can I do better  

UI goals:
Be minimalistic and also eye catching and simple
See only whats important, other things can be opened via interactions 
Make it as effortless as possible 
Nothing Extra that isnt needed
